# Playground

Маленька бібліотека утиліт для вітрини магазину. JavaScript (ESM), без залежностей.

## Команди
- `npm test` — усі тести (вбудований `node --test`, шукає `test/*.test.js`).

## Правила
- Одна утиліта = один файл `src/<name>.js` з одним іменованим експортом і JSDoc.
- Кожна утиліта має тест `test/<name>.test.js`; щонайменше: звичайний випадок, крайній випадок, некоректний вхід.
- Гроші завжди в копійках (цілі числа), ніколи не float.
- Не додавай залежностей і не чіпай `package.json`.
- Відповідай українською, коротко: що зроблено і результат `npm test`.
