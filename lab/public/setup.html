Як підключити модель

Це необов'язково: усі уроки працюють на заготовлених відповідях. Але з живою моделлю цікавіше подивитись, як той самий код керує нею.

Перевіряю, чи вже щось підключено…

Варіант 1. Ollama: локально і безкоштовно

Модель працює прямо на твоєму комп'ютері, ключ не потрібен. Потрібно близько 16 ГБ оперативної пам'яті і 5 ГБ на диску.

  1. Постав Ollama. Програма для macOS, Windows і Linux є на ollama.com/download. На macOS можна через Homebrew: 
    brew install ollama
brew services start ollama
  2. Завантаж модель (близько 5 ГБ, один раз): 
    ollama pull qwen3:8b
  3. Перевір, що вона є: 
    ollama list
    У списку має бути qwen3:8b.
  4. Натисни «Перевірити ще раз» нижче або під кодом в уроці. Перезапускати лабораторію не треба.

Перша відповідь може йти 10–30 секунд, поки модель завантажується в пам'ять, далі буде кілька секунд. Чому qwen3:8b: я пробував кілька маленьких моделей на завданнях з уроку, і вона доводила задачу до кінця. Менші часто кидали її на півдорозі.

Варіант 2. Хмарний API з безкоштовним лімітом

Підходить, якщо комп'ютер слабкий. OpenRouter, Groq і Gemini мають безкоштовні ліміти.

  1. Зареєструйся на сайті сервісу і створи API-ключ.
  2. У папці проєкту скопіюй файл з налаштуваннями (на Windows: copy .env.example .env): 
    cp .env.example .env
  3. Відкрий .env, розкоментуй блок свого сервісу і впиши ключ (OPENAI_API_KEY) і назву моделі (OPENAI_MODEL) з сайту сервісу. Обирай модель, яка вміє працювати з інструментами (tool calling).
  4. Перезапусти лабораторію: Ctrl+C у терміналі, потім знову npm run lab.

Варіант 3. Claude від Anthropic (платно)

Найрозумніша з трьох, проходить усі кроки без пригод. Урок коштує частки цента. У .env розкоментуй ANTHROPIC_API_KEY=, впиши свій ключ з console.anthropic.com і перезапусти лабораторію.

Якщо заповнено кілька варіантів, лабораторія бере перший у такому порядку: Claude → хмарний API → Ollama. Файл .env у git не потрапляє, а ключі бачить тільки сервер лабораторії на твоєму комп'ютері.

Якщо не працює

«Справжня модель · не підключена», хоча Ollama стоїть
Перевір, що Ollama запущена: ollama list має показати список без помилок. На macOS: brew services start ollama або відкрий програму Ollama.
«Ollama запущена, але моделей у ній немає»
ollama pull qwen3:8b
«У .env бракує: …» або «OPENAI_BASE_URL має бути повною адресою»
Заповни всі три рядки OPENAI_…, адреса має починатися з https://. Перезапусти лабораторію.
Модель «тупить»: зупиняється на півдорозі або просить не той інструмент
Для маленьких моделей це нормально, тому в коді агента і є обмеження спроб і перевірки. Спробуй ще раз або підключи більшу модель.
